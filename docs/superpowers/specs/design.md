# 佛前投币 · 设计文档

> 纯静态 H5 游戏（单文件 `index.html` + `assets/` 像素素材），移动优先 + 微信 webview 适配，接入 `GamePlatform` SDK 登录门控，娱乐向不进天梯榜。

## 1. 玩法与核心循环

- 进入后**左右滑动选佛**：横向轮播，佛数量 5–10 尊（含观音），滑到最右空白位置 = 「信自己」（纯随缘，应验率 50%）。
- 每尊佛带像素立绘 + 专属吉祥语 + 应验率（50%–60% 区间，信自己固定 50%）。
- 写心愿（中文输入框，支持微信输入）→ 点「投币」。
- 硬币 3D 翻转（rotateY）落定，判定：
  - 正面（字）= 佛接纳：金色光晕 + 「✨ 佛已应允」+ 该佛吉祥语。
  - 反面（花）= 未中：「🪙 再试一次」，本轮继续，累计次数。
- **结算时机（手动）**：玩家可一直投，点「结束本次」才把本轮（无论是否中）记入最近 10 次历史，开启新一轮许愿。
- 判定随机：`Math.random() < 佛.应验率` 为正面；同佛多次投币相互独立。

## 2. 界面（移动优先，max-width ~420px 居中）

- **顶部**：仅标题「🙏 佛前投币」，无副标题。
- **佛像区**：左右滑动切换 5–10 尊佛 + 空白「信自己」，像素立绘。
- **许愿区**：心愿输入框。
- **硬币区**：中央硬币（CSS 容器 + 正/反两面像素图），点击「投币」触发翻转。
- **状态区**：仅显示「本次已投 N 次 / 当前连续未中 N 次」；不含历史最佳。
- **底部**：最近 10 次历史列表（佛 / 心愿 / 投了几回 / 是否中 / 时间）。
- **操作按钮**：投币、结束本次。

## 3. 数据与集成

- **本地数据**（localStorage key `coin-toss:history`）：数组，每条 `{ wish, buddha, throws, accepted, ts }`，仅保留最近 10 条。
- **GamePlatform 集成**（同 holy-grail）：
  - `<script src="https://api.w1lkin.site/sdk.js">` 引入 `GamePlatform`。
  - `GP.init()` + 登录门控（未登录弹登录框）。
  - `coin-toss` 在 game-api `games` 表登记为 `skip:true`：在 game-list 可见可跳转，不进天梯榜（不改天梯排序逻辑）。
- **素材**：从免费可商用游戏素材站（OpenGameArt / kenney.nl / itch.io 免费区）找像素硬币（正/反）+ 5–10 尊佛像素立绘，下载到 `coin-toss/assets/` 本地引用，离线可用。
- **部署**：新 Cloudflare Pages 项目（独立域名，如 `coin-toss-xxx.pages.dev`），纯静态托管 `index.html` + `assets/`。
